# Visual system

The site is used by visitors on phones in daylight and by members reading church updates at home. Use a white reading surface, a committed PCG-blue welcome section and clear navy typography. Preserve existing brand tokens and fonts.

## Typography
Source Serif 4 for welcoming display headings; Inter for navigation, body and forms. Body 17px minimum; secondary text 15px minimum. Headings wrap naturally with letter-spacing no tighter than -0.03em.

## Layout and components
Maximum content width 1200px. Generous section spacing; split hero with a Bible photograph. Content lists use ruled rows. White surfaces, restrained corners, strong blue action buttons, visible input labels and native details elements for FAQs. No fabricated content or numerical claims.

## States
Distinguish unavailable data from an empty collection. Forms report success only after durable storage. Errors preserve entered values. All primary flows work with keyboard navigation. Respect reduced motion.

## Church office
The admin surface uses the same blue identity with a restrained product register: Inter throughout, compact fixed type sizes, a persistent navigation rail, ruled data rows and familiar forms. Status colour communicates publication state; decoration never competes with the work.
